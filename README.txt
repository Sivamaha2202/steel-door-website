# IRONOVA — Steel Door & Window Frontend

A responsive HTML/CSS/JavaScript landing page inspired by the supplied architectural steel website references.

## Files
- index.html
- style.css
- script.js

## Run
Open `index.html` directly in Chrome.

## Included
- Dark premium architectural UI
- Fixed glass-style navigation
- Full-screen hero with scrolling/parallax image
- Steel Doors / Steel Windows collections
- Featured product cards
- Company statistics
- Why Us section
- Process section
- Studio section
- Quote modal form
- Responsive mobile menu
- Yellow/gold hover and accent system
